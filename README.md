# 痛扁小老頭

公園裡的小老頭整天碎碎念。操控黃色主角走來走去，用大肚子把他們撞飛！

直接用瀏覽器打開 `index.html` 就能玩，電腦和手機都可以。

## 操作

| | 電腦 | 手機 |
|---|---|---|
| 走路 | 方向鍵 或 WASD | 左半邊手指按住拖曳（虛擬搖桿） |
| 肚子撞 | 空白鍵 或 J | 右下角「撞！」或點右半邊 |

## 用 GitHub Pages 線上玩

到專案的 Settings → Pages，Source 選 `main` 分支、資料夾選 `/ (root)`，存檔後等一兩分鐘，就能用 `https://<你的帳號>.github.io/<專案名稱>/` 開來玩。
